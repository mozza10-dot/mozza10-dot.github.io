Audio Reactive Matrix

An 8 × 8 LED visualizer driven by microphone input, with a mode button and local Wi-Fi control.

My roleHardware and firmware integration
HardwareESP32-S3 · INMP441 · WS2812B matrix
Project stageFirmware package

01 / PURPOSEThe interaction

Microphone input drives an 8 × 8 LED animation with a mode button and local Wi-Fi control.

02 / HARDWAREMy contribution

The supplied package maps an INMP441 microphone and WS2812B matrix to ESP32-S3 firmware, including colour and current limiting.

03 / EVIDENCEDocumentation and status

Firmware and documentation package prepared; no physical build test is claimed here.

The source package records firmware · wiring notes for the Audio Reactive Matrix project.

The available visual is a firmware interface preview or documentation diagram; it is not a product photograph.
