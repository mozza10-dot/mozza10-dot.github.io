Robot Line Follower

An Arduino Nano robot built around custom infrared sensor and motor-driver PCBs, with chassis parts designed for the physical build.

My rolePCB layout and fabrication, chassis parts, Arduino programming
SystemArduino Nano, Altium Designer, infrared sensors, motor driver, C++
StatusFunctional prototype tested · Team project

01 / CASE STUDYThe system

The robot detects a track with infrared sensors and uses an Arduino Nano to control its motors through a dedicated motor-driver board. The mechanical parts hold the electronics in a compact chassis.

This project brought board layout, fabrication, programming, and physical integration into the same prototype.

02 / CASE STUDYMy contribution

  • Designed the infrared sensor and motor-driver PCB layouts in Altium Designer and fabricated the boards.
  • Designed chassis parts for component placement.
  • Programmed the Arduino Nano in C++ and supported integration and track testing.

03 / CASE STUDYTested result

The assembled robot successfully followed the test track during functional testing.

A final assembled-robot photo is not available in the supplied documentation. The PCB layouts and chassis CAD are the primary visual evidence shown here.
