ISS Tracker (CYD)

A desk display showing the ISS's received position, a simplified world map, and optional detail via a local web page.

My roleHardware and firmware integration
HardwareESP32 CYD · TFT · button · Wi-Fi
Project stageFirmware package

01 / PURPOSEThe interaction

The CYD fetches the current ISS position and shows it in a desk-friendly display and local web interface.

02 / HARDWAREMy contribution

The package uses the ESP32-2432S028R screen, a GPIO22 button and Wi-Fi; its world-map view visualizes received position, not an orbit prediction.

03 / EVIDENCEDocumentation and status

Firmware and documentation package prepared; no physical build test is claimed here.

The source package records firmware · documentation for the ISS Tracker (CYD) project.

The available visual is a firmware interface preview or documentation diagram; it is not a product photograph.
