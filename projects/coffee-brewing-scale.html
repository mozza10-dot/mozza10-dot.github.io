Coffee Brewing Scale

A coffee scale that combines live weight and brew timer on an OLED, with buttons and a phone page hosted by the ESP32.

My roleHardware and firmware integration
HardwareESP32-S3 · HX711 · load cell · OLED
Project stageFirmware package

01 / PURPOSEThe interaction

Live mass and brew time share an OLED screen, with tare and timer controls on the device.

02 / HARDWAREMy contribution

The supplied guide specifies an ESP32-S3, HX711, load cell and SSD1306 OLED, plus a first-use 500 g calibration step.

03 / EVIDENCEDocumentation and status

Firmware and documentation package prepared; no physical build test is claimed here.

The source package records firmware · setup guide for the Coffee Brewing Scale project.

The available visual is a firmware interface preview or documentation diagram; it is not a product photograph.
