Tilt Maze

A hand-tilted maze game that moves its player using motion-sensor input on an OLED screen.

My roleHardware and firmware integration
HardwareESP32-S3 · MPU6050 · OLED
Project stageDocumented project

01 / PURPOSEThe interaction

The player moves through the maze by tilting the whole device rather than using a joystick.

02 / HARDWAREMy contribution

The ESP32-S3 firmware uses MPU6050 motion readings to drive the compact OLED game interface.

03 / EVIDENCEDocumentation and status

Firmware and documentation package prepared; no physical build test is claimed here.

The source package records firmware · enclosure files · video for the Tilt Maze project.
